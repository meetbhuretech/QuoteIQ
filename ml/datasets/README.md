# Synthetic development dataset

`synthetic_dev.csv` is generated by `python -m quoteiq_ml.synthetic`.

Every row is labelled `data_origin=synthetic_dev`. The labels come from a documented formula plus noise inside `quoteiq_ml/synthetic.py`. They are not factory jobs. Do not report metrics from this file as verified manufacturing accuracy.

The generator's price table is used only to create labels. It is not imported by the API or the cost engine.
